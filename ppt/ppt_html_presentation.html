WHAT IS RAG?

Retrieval-Augmented Generation — The Core Concept

  • Retrieve: User asks a question. System converts it to a vector and searches the database for the most relevant document chunks.
  • Augment: The retrieved document chunks are added to the AI prompt as context, grounding the response in real data.
  • Generate: The LLM generates an accurate, cited answer using only the provided context — no hallucinations.

SYSTEM ARCHITECTURE

Complete Data Flow

  1. User Question: React Frontend
  2. FastAPI Backend: Receives & Routes
  3. Gemini Embed: Vectorize Query
  4. ChromaDB Search: Top-5 Chunks
  5. Gemini 1.5 Flash: Generate Answer (Streams back to user)

PROS & CONS

Advantages & Disadvantages

ADVANTAGES

  • 100% Free to Run: Gemini free tier + ChromaDB
  • No Hallucinations: Strictly from uploaded documents
  • Works Offline: Vector store is local
  • Easy to Scale: Add more docs anytime
  • Source Citations: Shows document origins

DISADVANTAGES

  • Rate Limited: Gemini free tier limits
  • No Real-Time Data: Only uploaded documents
  • Dimension Fixed: Re-ingest if model changes
  • No Auth: Base version lacks login
  • Large Files: Slower to process and chunk
